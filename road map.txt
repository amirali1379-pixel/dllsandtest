2. هر مرحله یک هدف مشخص دارد.
3. اول وضعیت موجود را بررسی می‌کنیم.
4. حدس درباره API ممنوع.
5. کد فقط وقتی نوشته می‌شود که دقیقاً بدانیم چرا لازم است.
6. Capture اصلی دست‌نخورده می‌ماند مگر اینکه خود مرحله صراحتاً نیاز داشته باشد.
7. Raw CSV هیچ‌وقت حذف یا overwrite نمی‌شود.
8. هر مرحله → Build → Run → نتیجه → تأیید → مرحله بعد.
